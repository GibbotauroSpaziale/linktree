# Gibbotauro Linktree — space.gibbotauro.com

Link-in-bio di **Gibbotauro Spaziale**, servito su `space.gibbotauro.com` (GitHub Pages, repo dedicata).
Pagina `noindex, nofollow`, mai linkata dal resto del sito — raggiungibile solo da chi ha l'URL.
Tutti i link sono assoluti; i token CSS sono duplicati di proposito per tenere la pagina autonoma.

## Struttura

```
/          space.gibbotauro.com
CNAME      space.gibbotauro.com
```

## Deploy

1. Push su GitHub (repo `gibbotauro-linktree`, branch `main`)
2. Pages → custom domain `space.gibbotauro.com` (CNAME già nel root)
3. DNS Aruba: `CNAME space` → `GibbotauroSpaziale.github.io.`
